# Server feature research

Compared with TeamSpeak 6 and Discord on 26 November 2026. These priorities reflect Korero’s self-hosted, voice-first design. Server settings now include audit history, a message of the day, a default role for new accounts, a server-wide voice bitrate, and custom-role deletion.

Korero already has hierarchical channels, inherited role overrides, channel passwords and capacity limits, temporary channels, expiring and use-limited invitations, account mute and deafen, timed bans, manual AFK, channel chat and DMs, attachments, and a host-side backup command. Each account currently holds one role. [Protocol](protocol.md), [database schema](../backend/src/database/schema.ts), [backups](deployment.md#backup-and-restore).

## Priorities

| Priority | Candidate | Fit for Korero and precedent |
| --- | --- | --- |
| 1 | Channel-scoped permissions and permission preview | Separate channel visibility from permission to join voice, and give moderators a dedicated permission to remove messages. Today Korero uses `join` for channel visibility and `deleteChannels` when deleting someone else’s channel message. Add an effective-permissions preview that shows which channel or parent supplied an override. Consider channel-scoped role assignments when admins need to delegate one room. TeamSpeak 6 has server and channel groups. Discord supports member and role channel overrides and a role preview. [Korero authorization](../backend/src/modules/realtime.ts), [TeamSpeak permissions](https://support.teamspeak.com/hc/en-us/articles/360002757557-Where-are-the-permissions), [Discord permissions](https://docs.discord.com/developers/topics/permissions), [Discord role preview](https://support.discord.com/hc/en-us/articles/360055709773-View-Server-As-Role-Permission-Guide). |
| 2 | Moderation between mute and ban | Add an expiring timeout that blocks messaging and voice participation while preserving authorized read access. Add optional moderator reasons to the audit log and a per-channel send cooldown. Discord documents timeouts, audit reasons, and slowmode. Configurable keyword and mention limits can follow if operators need them. [Discord timeout](https://support.discord.com/hc/en-us/articles/4413305239191-Time-Out-FAQ), [audit log](https://docs.discord.com/developers/resources/audit-log), [slowmode](https://support.discord.com/hc/en-us/articles/360016150952-Slowmode-FAQ), [AutoMod](https://support.discord.com/hc/en-us/articles/4421269296535-AutoMod-FAQ). |
| 3 | Cross-channel whisper | Let team leads push to talk to selected channels without leaving their own voice channel. Start with a separate hotkey, visible recipients, and server-side permission checks for each target. TeamSpeak 6 supports whisper lists, and TeamSpeak documents cross-channel and individual targeting for its whisper feature. [TeamSpeak 6 whisper list support](https://support.teamspeak.com/hc/en-us/articles/360019524677-How-to-import-bookmarks-and-identities-from-TS3-to-TeamSpeak-6), [TeamSpeak Whisper Lists](https://business.teamspeak.com/features/whisper-lists/). |
| 4 | Entry and idle voice routing | Allow the owner to select an entry room and optionally move idle participants to an AFK channel after a configured interval. Keep entry into voice opt-in and reserve a safe fallback if the configured room becomes unavailable. TeamSpeak describes a default entry channel, and Discord exposes an AFK channel and timeout. [TeamSpeak voice chat](https://support.teamspeak.com/hc/en-us/articles/35367762165405-How-to-voice-chat), [Discord server settings API](https://docs.discord.com/developers/resources/guild#modify-guild). |
| 5 | Moderated voice and scheduled events | Add a listen-only audience mode and a request-to-speak queue for briefings and community calls. Add scheduled voice events with optional reminders after the live workflow works. Discord’s Stage channels let moderators move audience members to the stage, and Scheduled Events notify members who register interest. [Discord Stage channels](https://support.discord.com/hc/en-us/articles/1500005513722-Stage-Channels-FAQ), [scheduled events](https://support.discord.com/hc/en-us/articles/4409494125719-Scheduled-Events). |
| 6 | Reusable server configuration | Add an admin export that can recreate channels, roles, and permission overrides on a fresh instance. Restrict this export to configuration so it can serve as a shareable template without account records, secrets, or messages. TeamSpeak 6 has in-client snapshots that include channels and permissions. Discord templates clone categories, channels, roles, and permissions. [TeamSpeak 6 snapshots](https://community.teamspeak.com/t/teamspeak-6-0-0-beta4-foundation-ii-update/64497), [Discord server templates](https://support.discord.com/hc/en-us/articles/360041033511-Server-Templates). |

## Later candidates

- **Onboarding.** Add rules acknowledgement and links to recommended rooms when operators need more than a welcome message and registration role. Discord offers rules screening and onboarding questions that select roles and channels. Discord invites can also grant temporary membership, which addresses a different need from Korero’s registration tokens with expiry and use limits. [Discord rules screening](https://support.discord.com/hc/en-us/articles/1500000466882-Rules-Screening-FAQ), [community onboarding](https://support.discord.com/hc/en-us/articles/11074987197975-Community-Onboarding-FAQ), [invites](https://support.discord.com/hc/en-us/articles/208866998-Invites-101).
- **Chat retrieval and organization.** Start with pins and authorized search over retained messages. Consider threads if conversations regularly outgrow channel chat. TeamSpeak 6 also offers a room file browser with channel file transfer, a separate workflow from Korero’s message attachments. [Discord pins](https://support.discord.com/hc/en-us/articles/221421867-Pin-Messages-FAQ), [search](https://support.discord.com/hc/en-us/articles/115000468588-How-to-Use-Search-on-Discord), [threads](https://support.discord.com/hc/en-us/articles/4404809613847-Threads-Moderation-FAQ), [TeamSpeak 6 channel file transfer](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513).
- **Integrations.** Begin with revocable, channel-scoped incoming webhooks for event or service notifications if operators request automation. TeamSpeak 6 provides ServerQuery for server automation, and Discord offers incoming webhooks for posting into individual channels. [TeamSpeak 6 ServerQuery release notes](https://github.com/teamspeak/teamspeak6-server/releases), [Discord webhooks](https://docs.discord.com/developers/resources/webhook).
