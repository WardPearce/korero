# VNX.chat feature comparison with TeamSpeak 6 and Discord

**26 November 2026.** The VNX.chat baseline is this working tree at `e77b7f0`, including local changes. Findings describe the first-party client, server and protocol in that checkout. Public deployment and release availability could not be verified. TeamSpeak's public downloads listed the desktop client at `6.0.0-beta5.1` and its self-hosted server at `6.0.0-beta14`. Discord features can depend on the client, server type or subscription. [VNX.chat README](../README.md), [TeamSpeak downloads](https://teamspeak.com/en/downloads/), [TeamSpeak server releases](https://github.com/teamspeak/teamspeak6-server/releases/tag/v6.0.0-beta14), [Discord server types](https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types).

TeamSpeak 6 offers cross-channel voice, global hotkeys, multitrack local recording and deeper self-hosted administration. Discord offers standalone text channels, mature messaging, community moderation, event hosting and an app ecosystem. Both offer direct voice and camera calls, configurable global push-to-talk, group messaging, public discovery, and Windows and macOS desktop clients.

## Voice, video and platforms

| Capability | What competitors offer | VNX.chat in this checkout |
| --- | --- | --- |
| Direct calls and camera video | TeamSpeak's 1:1 calls support voice, camera and screen sharing without joining a common server or channel. Discord supports camera video in server voice channels and calls in 1:1 and group DMs. [TeamSpeak beta5](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513), [Discord video calls](https://support.discord.com/hc/en-us/articles/360041721052-Video-Calls), [Discord group calls](https://support.discord.com/hc/en-us/articles/223657667-Group-Chat-and-Calls). | Voice and screen sharing use joined channels. The first-party client captures displays through the system picker and has no camera or direct-call workflow. [Media protocol](protocol.md#webrtc-negotiation), [screen capture](../frontend/src/lib/media/screen-media.ts). |
| Cross-channel voice and hotkeys | TeamSpeak whisper lists route voice to selected channels or people. TeamSpeak 6 supports global hotkeys, including on supported Wayland environments. Discord's desktop push-to-talk can also work system-wide with a configurable keybind. [TeamSpeak 6 setup](https://support.teamspeak.com/hc/en-us/articles/360019524677-How-to-import-bookmarks-and-identities-from-TS3-to-TeamSpeak-6), [whisper routing](https://business.teamspeak.com/features/whisper-lists/), [TeamSpeak beta5](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513), [Discord push-to-talk](https://support.discord.com/hc/en-us/articles/211376518-Voice-Input-Modes-101-Push-to-Talk-Voice-Activated). | Voice follows the joined channel. Push-to-talk uses a fixed Alt+V shortcut in the focused window and releases it when the window loses focus. [Media protocol](protocol.md#webrtc-negotiation), [push-to-talk handler](../frontend/src/lib/media/audio.svelte.ts), [window events](../frontend/src/routes/+layout.svelte). |
| Stream controls and recording | TeamSpeak offers multi-application audio capture with per-app volume, picture-in-picture, stream popouts and local recording with per-speaker tracks and a master mix. Discord offers popout and simultaneous viewing of streams, plus Clips and Auto Clips in a Windows Nitro early-access rollout. [TeamSpeak beta5](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513), [Discord multistream](https://support.discord.com/hc/en-us/articles/360045784891-Video-Screenshare-Updates-Multistream-and-More), [Discord Clips](https://support.discord.com/hc/en-us/articles/16861982215703-Clips-and-Auto-Clips-FAQ). | The local screen-sharing changes include resolution, frame-rate and bitrate controls and one optional source-audio track. The client watches one selected share at a time and has no built-in recording or clipping workflow. [README](../README.md#share-and-chat), [screen sharing component](../frontend/src/lib/components/media/ScreenSharing.svelte), [media protocol](protocol.md#webrtc-negotiation). |
| Voice tuning | TeamSpeak exposes codec selection. Discord's desktop Priority Speaker lowers other voices while a designated speaker uses the priority keybind. [TeamSpeak voice features](https://teamspeak.com/en/), [Discord Priority Speaker](https://support.discord.com/hc/en-us/articles/360011876531-Setting-up-Priority-Speaker). | VNX.chat uses Opus with adjustable channel bitrate, and the client already provides input and output device selection, gain, echo cancellation, noise suppression, and per-member playback volume. [Media protocol](protocol.md#webrtc-negotiation), [audio settings](../frontend/src/routes/settings/audio/+page.svelte), [local audio preferences](../frontend/src/lib/preferences.ts). |
| Client availability | TeamSpeak 6 publishes Windows, macOS and Linux desktop builds. Its Android and iOS apps are listed under TeamSpeak 3 downloads. Discord supports those desktop platforms, supported browsers, iOS, Android and voice on Xbox and PlayStation. [TeamSpeak downloads](https://teamspeak.com/en/downloads/), [Discord system requirements](https://support.discord.com/hc/en-us/articles/213491697-What-are-the-OS-system-requirements-for-Discord), [Discord voice clients](https://support.discord.com/hc/en-us/articles/38025123604631-Minimum-Client-Version-Requirements-for-Voice-Chat). | Native microphone voice has a documented Linux x86-64 client. The browser frontend can handle administration, chat and screen sharing. Android microphone plugin source exists, with APK build and device verification pending. Windows, macOS, iOS and console voice clients are unverified in this checkout. [Client build guide](frontend-architecture.md), [README](../README.md#share-and-chat). |

## Messaging and social features

| Capability | What competitors offer | VNX.chat in this checkout |
| --- | --- | --- |
| Text without voice membership | Discord has standalone text channels alongside text chat attached to voice channels, forum channels with tags, public and private threads, and Community announcement channels that other servers can follow. [Discord channels API](https://docs.discord.com/developers/resources/channel), [forum channels](https://support.discord.com/hc/en-us/articles/6208479917079-Forum-Channels-FAQ), [announcement channels](https://support.discord.com/hc/en-us/articles/360032008192-Announcement-Channel-FAQ). | Channel messages and history require current channel membership and text permission. A server can retain channel history, and rooms can be nested, but the channel model has no separate text, forum, thread or announcement type. [Application requests](protocol.md#application-requests), [database schema](../backend/src/database/schema.ts). |
| Rich messages and retrieval | TeamSpeak 6 has replies, pins and a rich editor with preview, Markdown-style formatting, tables and diagrams. Discord has replies, edits, forwarding, pins, filtered search, reactions and custom emoji, stickers, polls and voice messages sent from mobile. [TeamSpeak beta4](https://community.teamspeak.com/t/teamspeak-6-0-0-beta4-foundation-ii-update/64497), [Discord messaging](https://support.discord.com/hc/en-us/sections/115000458672-Messaging-and-Chat), [Discord search](https://support.discord.com/hc/en-us/articles/115000468588-How-to-Use-Search-on-Discord), [Discord polls](https://support.discord.com/hc/en-us/articles/22163184112407-Polls-FAQ). | The client has plain-text messages, a Unicode emoji picker, attachment downloads, message deletion, optional history and channel-name search. The message API has send, list-history and delete operations. [Application requests](protocol.md#application-requests), [chat composer](../frontend/src/lib/components/chat/ChatComposer.svelte), [workspace](../frontend/src/routes/+page.svelte). |
| File sharing | TeamSpeak offers channel file transfer with its own file browser and controls. Discord supports inline media previews and a 20 MB free attachment limit, with higher limits on eligible paid plans. [TeamSpeak beta5](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513), [TeamSpeak file permissions](https://support.teamspeak.com/hc/en-us/articles/360002757557-Where-are-the-permissions), [Discord file previews](https://support.discord.com/hc/en-us/articles/1500005466681-File-Preview), [Discord file limits](https://support.discord.com/hc/en-us/articles/25444343291031-File-Attachments-FAQ). | VNX.chat attaches one file of up to 4 MiB to a channel message, with downloads tied to channel access and availability tied to message retention or temporary storage. [README](../README.md#share-and-chat), [application requests](protocol.md#application-requests). |
| Contacts and group inboxes | TeamSpeak has global contacts, group chats and device sync for bookmarks and identities. Discord has friends, group DMs and channel-level notification controls for all messages, mentions or mute, plus mobile push settings. [TeamSpeak contacts](https://support.teamspeak.com/hc/en-us/articles/360002743437-How-do-I-add-a-contact-and-start-a-chat-on-TeamSpeak-6), [TeamSpeak groups](https://support.teamspeak.com/hc/en-us/articles/4523999467933-Group-Chats-How-do-I-join-a-group-chat-how-do-I-create-a-group-chat), [TeamSpeak sync](https://support.teamspeak.com/hc/en-us/articles/360019524677-How-to-import-bookmarks-and-identities-from-TS3-to-TeamSpeak-6), [Discord group DMs](https://support.discord.com/hc/en-us/articles/223657667-Group-Chat-and-Calls), [Discord notifications](https://support.discord.com/hc/en-us/articles/215253258-Notifications-Settings-101). | The server protocol supports 1:1 text on the same instance. The first-party client exposes account-targeted sending through **Poke**, with no conversation inbox or group DM. Saved servers are local, and identity transfer uses an encrypted backup. [Application requests](protocol.md#application-requests), [Poke action](../frontend/src/lib/components/server/ChannelMember.svelte), [local preferences](../frontend/src/lib/preferences.ts), [identity settings](../frontend/src/routes/settings/identity/+page.svelte). |
| Public discovery and hosted communities | TeamSpeak lists public communities and offers first-party managed hosting. Discord lists eligible Discoverable servers and provides guided onboarding and rules screening for Community servers. [TeamSpeak discovery and hosting](https://teamspeak.com/en/), [Discord Discovery](https://support.discord.com/hc/en-us/articles/360030843331-Enabling-Server-Discovery), [Discord onboarding](https://support.discord.com/hc/en-us/articles/11074987197975-Community-Onboarding-FAQ), [Discord rules screening](https://support.discord.com/hc/en-us/articles/1500000466882-Rules-Screening-FAQ). | Users connect to a known self-hosted instance. The local administration UI provides a message of the day and default registration role, alongside invitations with expiry and usage limits. ## Administration, integrations and privacy

| Capability | What competitors offer | VNX.chat in this checkout |
| --- | --- | --- |
| Roles and permission tools | TeamSpeak has separately assignable server and channel groups. Discord members can hold several roles, channels can override permissions for individual members or roles, and admins can preview a role's view. [TeamSpeak permissions](https://support.teamspeak.com/hc/en-us/articles/360002757557-Where-are-the-permissions), [Discord permissions](https://docs.discord.com/developers/topics/permissions), [Discord role preview](https://support.discord.com/hc/en-us/articles/360055709773-View-Server-As-Role-Permission-Guide). | Each account holds one role with inherited per-role channel overrides. `join` also controls channel visibility, and deleting another member's channel message requires `deleteChannels`. The local administration UI supports creating, editing and deleting custom roles. [Database schema](../backend/src/database/schema.ts), [realtime authorisation](../backend/src/modules/realtime.ts), [server administration](../frontend/src/lib/components/server/ServerAdministration.svelte). |
| Moderation and voice routing | Discord has timeouts, audit reasons, slowmode, AutoMod keyword/spam filters, raid protection and a configured idle channel and timeout. TeamSpeak documents a default entry channel. [Discord timeout](https://support.discord.com/hc/en-us/articles/4413305239191-Time-Out-FAQ), [slowmode](https://support.discord.com/hc/en-us/articles/360016150952-Slowmode-FAQ), [AutoMod](https://support.discord.com/hc/en-us/articles/4421269296535-AutoMod-FAQ), [raid protection](https://support.discord.com/hc/en-us/articles/10989121220631-How-to-Protect-Your-Server-from-Raids-101), [Discord guild settings](https://docs.discord.com/developers/resources/guild#modify-guild), [TeamSpeak voice chat](https://support.teamspeak.com/hc/en-us/articles/35367762165405-How-to-voice-chat). | VNX.chat provides moves, kicks, timed bans, persistent moderator mute/deafen, a manual AFK state, basic rate limits and an audit log with actor and action filters. Users explicitly join a channel. [Protocol](protocol.md#websocket-connection-and-envelopes), [application requests](protocol.md#application-requests), [realtime moderation](../backend/src/modules/realtime.ts), [audit log UI](../frontend/src/lib/components/server/ServerAuditLog.svelte). |
| Live events and gaming tools | Discord offers Community Stage channels with audience/speaker roles and a request-to-speak queue, scheduled events and reminders, voice Soundboard, shared Activities and a Windows game overlay. [Stages](https://support.discord.com/hc/en-us/articles/1500005513722-Stage-Channels-FAQ), [events](https://support.discord.com/hc/en-us/articles/4409494125719-Scheduled-Events), [Soundboard](https://support.discord.com/hc/en-us/articles/12612888127767-Discord-Soundboard-Guide-Using-Adding-and-Managing-Sounds), [Activities](https://support.discord.com/hc/en-us/articles/21334461140375-Using-Apps-on-Discord), [Windows overlay](https://support.discord.com/hc/en-us/articles/217659737-Game-Overlay-101). | A VNX.chat room can restrict who may speak. Its protocol and client have no audience queue, scheduled events, shared sound effects, in-app activities or game overlay. [Application requests](protocol.md#application-requests), [workspace](../frontend/src/routes/+page.svelte). |
| Backup, automation and monitoring | TeamSpeak 6 has in-client server snapshots, ServerQuery over SSH or HTTP and an optional Prometheus endpoint. Discord has reusable configuration templates, installable bots, app commands, an App Directory and incoming webhooks. [TeamSpeak client snapshots](https://community.teamspeak.com/t/teamspeak-6-0-0-beta4-foundation-ii-update/64497), [TeamSpeak server releases](https://github.com/teamspeak/teamspeak6-server/releases/tag/v6.0.0-beta13), [Discord templates](https://support.discord.com/hc/en-us/articles/360041033511-Server-Templates), [Discord apps](https://support.discord.com/hc/en-us/articles/21334461140375-Using-Apps-on-Discord), [Discord webhooks](https://docs.discord.com/developers/resources/webhook). | VNX.chat has host-side backup/restore, health and readiness routes, diagnostics and an open client protocol. It has no configuration-template export, dedicated bot installation or webhook surface, or Prometheus endpoint. [VNX.chat backups](deployment.md#backup-and-restore), [HTTP and WebSocket protocol](protocol.md#http), [server routes](../backend/src/app.ts). |
| End-to-end encryption and account factors | Discord uses DAVE by default for voice, video and Go Live, with Stage channels exempt and text outside its scope. TeamSpeak advertises end-to-end encryption for global text chat. Both offer account 2FA with recovery codes, and Discord documents passkeys/security keys. [Discord DAVE](https://discord.com/blog/every-voice-and-video-call-on-discord-is-now-end-to-end-encrypted), [Discord MFA](https://support.discord.com/hc/en-us/articles/219576828-Setting-up-Multi-Factor-Authentication), [TeamSpeak global chat](https://teamspeak.com/en/), [TeamSpeak beta5](https://community.teamspeak.com/t/teamspeak-6-0-0-beta5-foundation-iii-update/65513). | VNX.chat signs login challenges with Ed25519 keys and provides revocable sessions and encrypted local identity export. WebRTC encrypts transport to the SFU, which is trusted for media. The server is also trusted with text. Account login has no optional second factor or recovery codes. [Authentication](authentication.md), [security](security.md), [identity settings](../frontend/src/routes/settings/identity/+page.svelte). |
